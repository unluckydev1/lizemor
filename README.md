# Lizemor

O projeto está dividido por responsabilidade:

- `index.html`: página principal, na raiz do projeto.
- `css/`: estilos base, layout, componentes, movimento e responsividade.
- `js/catalogo.js`: categorias, modelos, produtos 3D e caminhos das imagens.
- `js/app.js`: interações da loja, seleções e pedido.
- `assets/broches/`: modelos prontos e broches de tamanho.
- `assets/3d/`: produtos de impressão 3D.

Abra `index.html` no navegador e mantenha as pastas `css`, `js` e `assets` junto do `index.html` para que o site encontre seus arquivos.
